# Public repository privacy

The distribution separates source code from local user data. Runtime databases, model caches, account files, secrets, raw request dumps, notifications, browser profiles, private screenshots, Windows shortcuts and OS metadata must remain outside version control. Do not import an old private Git history into this public repository.

Home paths and private service addresses in examples are placeholders, not working endpoints. Third-party copyright and license notices remain attributed. The bundled notebooks have no stored execution output. Retained application artwork and icons have been reviewed and stripped of extraneous image metadata.

The application can send selected task text, research material and tool observations to the configured model/API endpoints. Local-first is not equivalent to offline operation. Review the chosen provider and data scope before enabling a feature. Do not publish personal trades, holdings, account IDs, conversation transcripts or credentials as validation evidence.

Before sharing, review the staged diff and run public source validation and a fresh secret scanner. A pattern scan cannot prove absence of all private data. The checked source tree and public reachable history are the scope of this distribution; previous provider-side commit objects, Actions metadata, caches and external copies are not erased. Keep OpenAI organization IDs and application contact details in the application form, not in this repository.
