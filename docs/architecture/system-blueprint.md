# 股市完整生態系系統藍圖

## 1. 系統目標

建立一個能讓使用者用自然語言或條件式查詢「所有股市相關資訊」的系統。它要回答的不只是：

- `台積電今天多少錢？`

而是能回答：

- `台積電今天為什麼跌？`
- `美債殖利率上升對台積電、AI 伺服器、半導體設備有什麼影響？`
- `今天台股強勢族群是什麼？原因是資金、新聞、財報還是國際市場？`
- `同樣是 AI 概念股，誰的基本面、籌碼、技術面比較健康？`
- `某檔股票和美元、日圓、油價、費半、NASDAQ 的連動程度如何？`

## 2. 分層架構

```text
使用者查詢層
  └─ Web / App / Chat UI / API

AI 理解與回答層
  ├─ 自然語言理解
  ├─ 查詢路由 Query Router
  ├─ RAG 文件檢索
  ├─ 知識圖譜推理
  └─ 回答產生與引用來源

市場知識層
  ├─ 股票實體：公司、ETF、指數、產業、概念股
  ├─ 事件實體：財報、法說、政策、新聞、併購、產品發表
  ├─ 關係：供應鏈、同業、客戶、匯率敏感、利率敏感、商品敏感
  └─ 指標：估值、成長、獲利、籌碼、動能、風險

資料服務層
  ├─ 行情服務 Market Data Service
  ├─ 基本面服務 Fundamentals Service
  ├─ 新聞事件服務 News/Event Service
  ├─ 總經服務 Macro Service
  ├─ 籌碼服務 Flow/Ownership Service
  └─ 關聯分析服務 Linkage Service

資料儲存層
  ├─ 時序資料庫：價格、成交量、利率、匯率、商品
  ├─ 關聯式資料庫：公司資料、財報、指標、事件
  ├─ 向量資料庫：新聞、法說、財報文字、研究報告摘要
  └─ 圖資料庫：公司、產業、供應鏈、跨市場連動

資料擷取層
  ├─ API connectors
  ├─ Web crawlers
  ├─ 檔案匯入 CSV/Excel
  ├─ 排程更新 jobs
  └─ 資料品質檢查
```

## 3. 核心模組

### A. Entity Master：市場實體總表

統一管理所有可查詢標的：

- 股票：ticker、交易所、公司名稱、產業、幣別。
- ETF：追蹤指數、成分股、費用率。
- 指數：台灣加權、櫃買、S&P 500、NASDAQ、費半等。
- 商品：原油、黃金、銅、天然氣。
- 匯率：USD/TWD、USD/JPY、CNH、EUR/USD。
- 利率：美債 2Y/10Y、Fed funds、台灣利率。
- 事件：財報、法說、除權息、政策、新聞。

### B. Data Connectors：資料連接器

每個資料來源都包成獨立 connector，輸出統一格式：

```json
{
  "source": "資料來源名稱",
  "entity_id": "2330.TW",
  "data_type": "price_daily",
  "timestamp": "2026-07-01T00:00:00+08:00",
  "payload": {},
  "quality_score": 0.98
}
```

### C. Query Router：查詢路由

把使用者問題分成不同查詢類型：

- 行情查詢：查價、K 線、漲跌幅。
- 原因解釋：今天為什麼漲跌。
- 比較分析：同業/同概念/同 ETF 成分股比較。
- 連動分析：與美股、匯率、利率、商品、新聞連動。
- 風險掃描：事件、估值、籌碼、技術破線。
- 機會掃描：強勢股、資金流、財報成長、產業趨勢。

### D. Market Linkage Engine：市場連動引擎

建立「變數 → 影響標的 → 影響方向 → 信心分數」：

```text
美債殖利率上升
  → 成長股估值壓力增加
  → NASDAQ / 半導體 / 高本益比股可能承壓
  → 台股電子權值股受到外資與估值影響
```

### E. AI Answer Engine：AI 回答引擎

回答必須包含：

1. 結論。
2. 依據資料。
3. 連動關係。
4. 不確定性與風險。
5. 可追蹤來源。

## 4. MVP 邊界

第一版不要一次做全市場，建議：

- 市場：台股 + 美股主要指數。
- 個股：台股上市櫃 + 美股大型股。
- 資料：日線價格、基本面季資料、法人籌碼、新聞摘要、總經指標。
- AI：先做 RAG + 規則化連動模型，不先做自動交易。

## 5. 成功標準

MVP 成功時，使用者可以問：

- `2330 最近一週走勢如何？`
- `今天半導體族群為什麼強？`
- `美債 10 年期殖利率上升，哪些台股可能受影響？`
- `台積電、聯電、世界先進的基本面和技術面比較。`
- `幫我找出今天量價齊揚且法人買超的 AI 概念股。`

系統要能回傳有資料依據的答案，而不是空泛評論。
