# 使用者查詢能力設計

## 1. 查詢入口

使用者可以用三種方式查詢：

1. 自然語言：`台積電今天為什麼跌？`
2. 條件篩選：`找出台股成交量放大 2 倍且法人連買 3 天的股票`
3. API/儀表板：前端下拉選擇市場、產業、指標、期間。

## 2. 查詢類型

### A. 單一標的查詢

範例：

- `2330 現在股價？`
- `台積電最近一年 EPS 和本益比？`
- `NVDA 財報後走勢如何？`

回覆包含：

- 最新價格與漲跌。
- 近期走勢。
- 基本面摘要。
- 重要事件。
- 相關市場變數。

### B. 原因解釋查詢

範例：

- `今天台股為什麼大跌？`
- `為什麼航運股今天大漲？`

查詢流程：

1. 檢查個股/族群/指數價格異動。
2. 檢查成交量是否放大。
3. 檢查新聞與公告。
4. 檢查同族群是否同步。
5. 檢查跨市場：美股、匯率、利率、商品。
6. 檢查籌碼：法人、融資融券。
7. 產生「可能原因排序」。

### C. 比較查詢

範例：

- `台積電、聯電、世界先進誰比較強？`
- `AI 伺服器概念股誰營收成長最快？`

比較維度：

- 估值：PE、PB、PS、EV/EBITDA。
- 成長：營收 YoY、EPS YoY、毛利率趨勢。
- 品質：ROE、自由現金流、負債比。
- 技術：趨勢、均線、相對強弱。
- 籌碼：法人買賣、融資融券。
- 事件：近期新聞、財報、法說。

### D. 條件掃描

範例：

- `找出今天突破 20 日線且成交量放大的股票`
- `找出本益比低於 15、ROE 高於 15%、營收年增的台股`
- `找出受惠日圓貶值的台股`

輸出：

- 股票清單。
- 排名原因。
- 指標數值。
- 風險註記。

### E. 市場連動查詢

範例：

- `美元走強會影響哪些台股？`
- `油價上漲對台股哪些產業有利/不利？`
- `費半大跌，台股哪些股票風險最大？`

輸出：

- 受影響標的。
- 影響方向：正向/負向/不確定。
- 連動機制。
- 歷史相關性。
- 近期事件佐證。

## 3. 回答格式標準

每個 AI 回答盡量固定格式：

```text
結論：一句話回答。

重點依據：
1. 價格/量能：...
2. 基本面：...
3. 籌碼：...
4. 新聞/事件：...
5. 跨市場連動：...

影響路徑：
A → B → C

風險與不確定性：
- ...

資料來源：
- source 1
- source 2
```

## 4. AI 不應該做的事

MVP 階段先避免：

- 直接給保證獲利建議。
- 沒有資料就硬解釋原因。
- 把相關性說成因果。
- 隱藏資料來源。
- 自動下單。

| 財報、EPS、營收、毛利 | fundamentals |
| 法人、外資、投信、融資 | flow |
| 新聞、公告、法說 | event |
